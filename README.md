# 🐙 GitLingo - El Duolingo del Código

> Aprende Git, GitHub y VS Code de forma divertida y gamificada, optimizado para tablet y celular.

## 🚀 Inicio rápido

```bash
cd github-duolingo
npm install
npm run dev
```

Abre en tu celular/tablet: `http://localhost:5173`

## 📱 5 Módulos principales

| Módulo | Qué aprenderás |
|--------|----------------|
| 📚 **Lecciones** | Git, GitHub, VS Code con preguntas interactivas |
| 🐙 **GitHub Sim** | Crea repos, commits, branches, issues |
| 💻 **VS Code Sim** | Editor real con syntax highlight y terminal |
| 🤖 **Guía IA** | Chat con Octo, tu asistente de programación |
| 🍅 **Pomodoro** | Timer de estudio 25min + descansos |

## 🎮 Gamificación

- ⭐ **XP** por cada acción (lecciones, commits, pomodoros)
- 🔥 **Racha diaria** (streak) para mantener consistencia
- ❤️ **Corazones** (lives) - los pierdes si te equivocas
- 💎 **Gemas** para comprar corazones
- 🏆 **Niveles** que suben con XP

## 🇺🇸 Inglés técnico incluido

Cada término en inglés incluye su traducción. Ejemplos:
- `commit` = Confirmar/Guardar
- `branch` = Rama
- `repository` = Repositorio
- `merge` = Fusionar
- `push` = Subir/Empujar

## 🛠️ Stack

React 19 + Vite 7 + Tailwind CSS 4 + Zustand
